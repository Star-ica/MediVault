# MediVault
1. Deploy `contract/MediVault.sol` (Remix/Hardhat) on BOT Chain. The deployer becomes admin.
2. Set `CONTRACT_ADDRESS` in `js/app.js`.
3. Serve the folder (e.g. VS Code Live Server) and open `index.html`.
Roles: Admin registers hospitals; hospitals add records; patients grant/revoke doctors; doctors load a patient's records by address.
Store only hashes/CIDs of encrypted files. Not audited; test on a testnet first.
